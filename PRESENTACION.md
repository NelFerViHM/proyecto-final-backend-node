
Hola, ¿cómo están? Comparto el enlace al repositorio de mi  **Proyecto Final de Back End con Node.js** :

🔗 **Repositorio:** https://github.com/NelFerViHM/proyecto-final-backend-node

Desarrollé una API RESTful para la gestión de productos utilizando  **Node.js** , **Express** (con ES Modules) y **Cloud Firestore** como base de datos en la nube, organizada bajo una arquitectura modular por capas (`routes`, `middlewares`, `controllers`, `services` y `models`).

El sistema incluye autenticación mediante **JSON Web Tokens (JWT)** (`POST /api/auth/login`) que protege las operaciones críticas de creación (`POST /api/products/create`) y eliminación (`DELETE /api/products/:id`), manteniendo públicas las consultas (`GET`), junto con validaciones de negocio, manejo global de errores `404` y variables de entorno protegidas.

En el repositorio adjunto tanto el **`README.md`** con las instrucciones de instalación y ejemplos de uso, como una **`BITACORA.md`** donde documenté paso a paso cada hito del desarrollo. ¡Quedo atento a cualquier devolución!
